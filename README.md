# Scene BGM (실리태번 확장)

대화 분위기를 읽고 유튜브에서 어울리는 음악을 찾아 플로팅 플레이어로 틀어줍니다.

## 설치

**주소로 설치 (간단)**: 실리태번 확장 메뉴 → **Install extension** → 아래 주소 붙여넣기

```
https://github.com/athenawin00-boop/scene-bgm
```

**직접 넣기**

1. 실리태번을 끕니다.
2. 이 저장소 폴더를 통째로 아래 위치에 넣습니다.
   - `SillyTavern/data/default-user/extensions/` (내 계정에만)
   - 또는 `SillyTavern/public/scripts/extensions/third-party/` (모든 계정)
3. 실리태번을 켜고 새로고침. 오른쪽 위에 플레이어 창이 뜹니다.
4. 확장(블록 아이콘) 메뉴 → **Scene BGM**에서 설정합니다.

## 사용법

| 요소 | 설명 |
|---|---|
| 자동 / 추천 / 수동 | 자동: 분위기 바뀌면 바로 교체 · 추천: 후보 3개만 띄움 · 수동: 🪄 버튼 누를 때만 |
| ⏻ | 끄면 음악 정지 + 판단 중지 |
| − | 미니 모드(재생 바만) |
| × | 창만 닫기(음악은 계속). 다시 열기: 입력창의 ♫ 버튼 (또는 마법봉 메뉴 → Scene BGM) |
| 🪄 | 지금 장면에 맞는 곡 바로 찾기 |
| 🔄 | 이 곡 말고 새로 고르기 (같은 장면, 다른 결의 곡) |
| ♡ | 좋아요 — 지금 채팅(채팅 파일)에 기록. 판단할 때 취향 힌트로도 씀 |
| 🔁 | 누를 때마다 반복 끔 → 한 곡 반복 → 좋아요 곡만 반복 |
| ⊘ | 이 곡 / 이 채널 전체 다시 안 고르기 |
| 상태 줄 | 판단 이유가 흘러가며 보임. 누르면 분위기·검색어·모델의 생각까지 펼쳐짐 |
| 장르 ▸ | 눌러서 펼치기/접기. 잔잔·배경 / 장면·세계관 / 대중음악 31종 |
| 탭 | 대기열 · 비슷한 곡 · 기록 · 좋아요(이 채팅 / 전체). 유튜브 아이콘은 유튜브로 이동 |
| 직접 넣기 | 대기열 탭 맨 위 칸에 유튜브 주소(일반·youtu.be·Music·쇼츠)를 붙여넣고 Enter |
| 메시지 🎵 | 메시지의 ⋯ 메뉴 안. 그 메시지까지의 대화로 곡을 골라요(지나간 장면도 됨). 고른 곡은 그 메시지에 카드로 남아요 |
| 목록 줄 | 대기열: 누르면 그 곡부터, − 는 대기열에서 빼기 · 다른 탭: 누르면 지금 곡 다음에 끼워서 바로 재생(대기열은 그대로), ≡ 는 다음 곡으로 넣기 |

입력창 오른쪽의 ♫ 버튼으로 창을 바로 열고 닫을 수 있어요. 재생 중이면 ♫ 옆에 작은 점이 깜빡여요.

모바일에서는 창이 입력창 바로 위에 붙고, 키보드가 올라오면 같이 올라갑니다. 볼륨은 기기 버튼으로 조절해요(iOS는 웹에서 볼륨을 바꿀 수 없음).

PC에서는 창 제목줄을 끌어서 옮기고, 오른쪽 아래 모서리로 크기를 바꿉니다. 위치와 크기는 저장됩니다.

슬래시 명령: `/bgm`(장면으로 찾기), `/bgm next`, `/bgm prev`, `/bgm reroll`, `/bgm toggle`, `/bgm on`, `/bgm off`, `/bgm window`, `/bgm 검색어`(직접 검색해서 재생)

## 곡 카드

설정의 **AI 답장에 곡 카드 넣기**를 켜면, 답장을 쓰는 메인 모델이 N번째 답장마다(기본 6) 답장 끝에 곡 하나를 적고 그 메시지 위에 카드가 붙어요.

- 판단 프로필 호출이 따로 들지 않아요. 이야기를 쓰는 모델이 직접 고르니 장면 이해가 가장 정확해요.
- 카드가 붙은 답장이 오면 그 곡을 바로 틀어요(설정에서 끌 수 있음). 그 답장에는 판단 프로필을 부르지 않아요.
- 카드를 누르면 재생/일시정지, 꾹 누르면(PC는 우클릭) 유튜브 열기·좋아요·지우기.
- 모양: 알약, 미니 플레이어, 한 줄 글자, LP판, 진행 막대.
- 모델이 적는 `<bgm …>` 한 줄은 화면에선 숨겨지지만 메시지에는 남아요. 메시지 🎵로 남긴 카드는 본문을 건드리지 않고 채팅 파일에 따로 저장돼요.

## 알아둘 점

- 추론(thinking) 모델을 판단용으로 쓰면 답이 비어 올 수 있어요. 설정에서 "판단 최대 토큰"을 1500 이상으로 올리세요.
- 기본은 **실제 곡 추천**: AI가 장면에 맞는 아티스트·곡명 5개를 고르고, 확장이 유튜브에서 그 곡(공식·Topic 채널 우선, 커버·가사·1시간 반복 영상은 뒤로)을 찾아 틀어요. 설정 '곡 고르는 방식'에서 예전처럼 분위기 검색으로 바꿀 수 있어요.
- 유명 가수 공식 영상은 권리자가 다른 사이트 재생을 막아 둔 경우가 많아요. 막히면 먼저 **같은 곡의 다른 업로드**(Topic 음원 → 공식 오디오 → 가사 영상)를 자동으로 시도하고, 그것도 다 막혔을 때만 **'유튜브 창에서 듣기'** 버튼이 떠요. 누르면 남은 대기열 전체가 유튜브 창에서 재생목록으로 이어서 재생되고, 그동안 분위기가 바뀌면 새 곡을 '유튜브 창에서 / 여기서' 고를 수 있게 띄워 줍니다. (실리태번 보안 설정 때문에 띄운 창을 조종할 수는 없어서, 새 재생목록은 새 창으로 열려요)
- 설정에서 '건너뛰기'로 바꾸면 막힌 곡은 조용히 건너뜁니다.
- **AI 생성 음악 거르기**(기본 켬): 유튜브의 'AI·합성 콘텐츠' 표시나 설명란의 AI 제작 문구가 있는 영상은 건너뛰고, 그 채널을 기억해 다음부터 검색 단계에서 뺍니다. 표시를 안 한 AI 채널은 ⊘ → '이 채널 전체 안 듣기'로 막으세요.
- 브라우저가 소리 있는 자동재생을 막으면 안내가 뜨고 ▶ 버튼이 깜빡여요. 한 번 눌러 주세요. **아이폰·아이패드**는 바깥 버튼으로 재생을 시작할 수 없어서 창이 열리면 영상을 직접 한 번 눌러야 해요.
- 같은 영상도 기기·브라우저에 따라 막히기도 해서, 막힌 영상은 **그 기기에만** 기억해요. PC에서 막힌 곡이 휴대폰에서 안 나오는 일은 없어요.
- "실리태번 서버 경유" 검색은 유튜브 페이지를 읽는 방식이라, 유튜브가 페이지 구조를 바꾸면 고장날 수 있습니다. 그때는 API 키 방식으로 바꾸세요.

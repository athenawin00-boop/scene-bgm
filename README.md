# Scene BGM (실리태번 확장)

대화 분위기를 읽고 유튜브에서 어울리는 음악을 찾아 플로팅 플레이어로 틀어줍니다.

## 설치

**주소로 설치 (간단)**: 실리태번 확장 메뉴 → **Install extension** → 아래 주소 붙여넣기

```
https://github.com/athenawin00-boop/scene-bgm
```

**직접 넣기**

1. 실리태번을 끕니다.
2. 이 저장소 폴더를 통째로 아래 위치에 넣습니다.
   - `SillyTavern/data/default-user/extensions/` (내 계정에만)
   - 또는 `SillyTavern/public/scripts/extensions/third-party/` (모든 계정)
3. 실리태번을 켜고 새로고침. 오른쪽 위에 플레이어 창이 뜹니다.
4. 확장(블록 아이콘) 메뉴 → **Scene BGM**에서 설정합니다.

## 처음 할 것

- **판단에 쓸 연결 프로필**: 연결 프로필 기능으로 저렴한 모델(예: Gemini Flash) 프로필을 하나 만들어 두고 고르세요. 비워두면 메인 API를 씁니다.
- **장르**: 창 안의 장르 칩이나 설정에서 고릅니다. "○○만 장르 따로 저장"을 켜면 캐릭터·그룹마다 따로 기억합니다.
- **검색 방식**: 기본은 "실리태번 서버 경유"(키 필요 없음). 안 되면 YouTube Data API 키를 넣고 바꾸세요.

## 사용법

| 요소 | 설명 |
|---|---|
| 자동 / 추천 / 수동 | 자동: 분위기 바뀌면 바로 교체 · 추천: 후보 3개만 띄움 · 수동: 🪄 버튼 누를 때만 |
| ⏻ | 끄면 음악 정지 + 판단 중지 |
| − | 미니 모드(재생 바만) |
| × | 창만 닫기(음악은 계속). 다시 열기: 입력창 왼쪽 마법봉 메뉴 → Scene BGM |
| 🪄 | 지금 장면에 맞는 곡 바로 찾기 |
| ♡ / ⊘ | 보관함에 담기 / 이 곡 다시 안 고르기 |
| 탭 | 대기열 · 비슷한 곡 · 기록 · 보관함. 줄을 누르면 재생, 유튜브 아이콘은 유튜브로 이동 |

PC에서는 창 제목줄을 끌어서 옮기고, 오른쪽 아래 모서리로 크기를 바꿉니다. 위치와 크기는 저장됩니다.

슬래시 명령: `/bgm`(장면으로 찾기), `/bgm next`, `/bgm prev`, `/bgm toggle`, `/bgm on`, `/bgm off`, `/bgm window`, `/bgm 검색어`(직접 검색해서 재생)

## 알아둘 점

- 추론(thinking) 모델을 판단용으로 쓰면 답이 비어 올 수 있어요. 설정에서 "판단 최대 토큰"을 1500 이상으로 올리세요.
- 일부 공식 뮤직비디오는 외부 재생이 막혀 있어서 자동으로 건너뜁니다.
- 브라우저가 소리 있는 자동재생을 막으면 처음 한 번은 ▶를 눌러야 할 수 있어요.
- "실리태번 서버 경유" 검색은 유튜브 페이지를 읽는 방식이라, 유튜브가 페이지 구조를 바꾸면 고장날 수 있습니다. 그때는 API 키 방식으로 바꾸세요.
